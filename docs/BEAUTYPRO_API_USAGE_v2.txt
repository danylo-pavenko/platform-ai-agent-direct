Що робить інтеграція
--------------------------------------------------------------------------------

Direct AI Agents — AI-асистент у Instagram Direct для салонів.
Підключення до BeautyPro дає:

  • синхронізацію довідників (філії, категорії, послуги, майстри, грейди);
  • пошук / створення / оновлення клієнта за телефоном або email;
  • показ вільних слотів за графіком майстра (free_time);
  • запис, скасування, зміну складу візиту, перенесення;
  • історію візитів для повторних клієнтів.

Запити виконуються з нашого сервера після авторизації (auth/database).
Для кожного салону потрібен Grant access у Marketplace BeautyPro.

1. Авторизація
--------------------------------------------------------------------------------

5. Записи (appointments)
--------------------------------------------------------------------------------

  POST /v1/appointments?force=true
  body: date, location, client, state=planned, comments?,
        services: [{ service, professional, start, duration }, …]
  → новий запис (book_appointment); merge same date+location+client — API

  PUT /v1/appointments/{id}?force=true
  body: services: [{ service, professional, start, duration, action: insert }, …]
  → додати послугу до існуючого візиту (повторний book на той самий слот)

  GET /v1/appointments/{id}
      ?fields=state,services(id,service,serviceName,start,duration,professional)
  → зчитати склад візиту перед remove / перевіркою

  PUT /v1/appointments/{id}?force=true
  body: services: [{ id: lineId, action: delete }]
  → прибрати одну послугу з візиту (remove_appointment_service);
    якщо залишилась одна — cancel замість delete

  PUT /v1/appointments/{id}
  body: state=cancelled, cancelReason=…
  → скасування візиту (cancel_appointment)

  GET /v1/appointments
      ?fields=date,location,client
      &client={id}&location={id}&from=…&to=…
      &state=planned,confirmed
  → пошук візиту на той самий день (merge / TIME_CONFLICT)

Перед POST/PUT звіряємо free_time (день відкритий, час у слотах).

--------------------------------------------------------------------------------
6. Операції агента → API (integration flow)
--------------------------------------------------------------------------------

  book_appointment (новий запис)
    GET /clients (phone) → POST /clients (якщо немає)
    GET /employees/free_time
    [GET /employees + GET /employees/pick_professional — якщо без master_id]
    POST /appointments?force=true

  cancel_appointment (скасування)
    PUT /appointments/{id}  state=cancelled

  remove_appointment_service (зміна складу — мінус послуга)
    GET /appointments/{id}
    PUT /appointments/{id}?force=true  services[].action=delete
    (або PUT state=cancelled, якщо була остання послуга)

  reschedule_appointment (перенесення)
    PUT /appointments/{old_id}  state=cancelled  (старий візит)
    GET /employees/free_time  (нова дата/час)
    POST /appointments?force=true  (новий візит)
    Окремого «move appointment» endpoint не використовуємо.

  get_available_slots
    GET /employees/free_time
    GET /employees?location=…  (labels майстрів)

  sync / admin probe
    GET /locations, /services/categories, /positions, /services, /employees

  get_client_crm_history
    GET /clients/{id}/history
    GET /sales/{sale_id}  (actual duration для paid visits)
